# SafeSync – Emergency Information Vault

SafeSync is a simple and mobile-friendly web application designed to store and quickly access important emergency information.

## Problem Statement

During emergency situations, accessing important contact details and instructions quickly can be difficult. SafeSync provides a simple digital vault for storing emergency information in one place.

## Features

- Store emergency contact information
- Save emergency instructions
- Offline data storage using LocalStorage
- Cloud sync status interface
- Mobile-friendly design
- Quick access to emergency information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

## How It Works

1. User opens the SafeSync application.
2. Emergency contact and instruction details can be entered.
3. Data is stored locally using browser LocalStorage.
4. Stored information can be accessed when required.
5. The application is designed to work without requiring continuous internet access.

## Project Goal

To provide quick and easy access to important emergency information during critical situations.

## Future Scope

- AWS S3 integration for cloud storage
- AWS IAM for access control
- AWS EC2 for cloud deployment
- Secure cloud synchronization
- User authentication

## Project Status
